    fix(constitution): add postflight check at advance-phase (closed-loop)
    
    Previously, constitution only ran in preflight mode — scanning the PRIOR
    phase's artifacts. A phase could produce low-quality documents (21%) and
    advance without detection, only caught at the NEXT phase's preflight.
    
    Changes:
    1. _advance_prechecks: add constitution postflight for ALL phases 1-8
       - Scans the CURRENT phase's own documents before advancing
       - Uses check_mode="postflight" (already supported in runner.py)
       - Exit code 16 = constitution below phase threshold
    2. _get_completed_phases: derive from current_phase (closed-loop)
       - current_phase=N → phases 1..N-1 implicitly completed
       - phase_completed key retained as legacy fallback
       - No agent action needed; advance-phase writes current_phase
    
    Both fixes together mean:
    - Each phase checks its OWN documents at advance time (postflight)
    - The next phase's preflight also checks prior documents (preflight)
    - Phase 1 with 21% constitution CANNOT advance to Phase 2
    
    Co-Authored-By: Claude Sonnet 4.6 <noreply@anthropic.com>
