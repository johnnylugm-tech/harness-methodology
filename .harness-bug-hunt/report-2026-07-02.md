# Bug Hunt Report — Non-test Source
**Date**: 2026-07-02
**Scope**: 341 files | python, javascript, typescript, bash
**Verified findings**: 13 confirmed / 25 reviewed / 34 raw

## TL;DR
Bugs cluster in **cross-cutting trust boundaries** — JSON payload deserialization (harness_bridge), filesystem path resolution (decision_log, harness_cli), and concurrency primitives (TOCTOU writes). Pattern: framework trusts agent-written artifacts without normalizing `None`/path/meta-chars before use. 一個共通毛病：boundaries 沒做 normalization。

## Confirmed Bugs (by severity desc)

### [CRITICAL] DecisionLogWriter TOCTOU + glob 元字符注入
- **File**: `harness/decision_log.py:49`
- **Function**: `DecisionLogWriter.write`
- **Defect**: `seq = len(d.glob(f"{agent_id}_{phase}_*.yaml")) + 1` — agent_id 未 sanitize 直接代入 glob；兩個 writer 同讀 len=N 都寫 `_N+1`，後者覆蓋前者。
- **Failure scenario**: `agent_id='AGENT*1'` 配 planted decoy `AGENTx1_3_001.yaml` → glob 跨檔匹配、seq 膨脹；10 threads 並行寫入只剩 3 個檔案、7 個 payload 靜默 clobber。
- **Referee reason**: 沒 lock、沒 atomic write、沒 compare-and-set，glob + write_text 之間完全無防護。
- **Fix**: seq 改 `uuid.uuid4().hex[:8]`；agent_id 用 `re.sub(r"[^A-Za-z0-9_-]", "_", agent_id)` escape；寫檔用 `O_CREAT|O_EXCL`，EEXIST retry。

### [HIGH] DriftDetector layer 比對 dotted vs slash
- **File**: `detection/drift_detector.py:665`
- **Function**: `_resolve_import_layer`
- **Defect**: `normalized = import_path.replace(".", "/")` 但 `layer_to_modules` 保留 dotted 形式，三個 startswith/equality 全部 miss。
- **Failure scenario**: SAB 層宣告 `core.quality_gate`，`from core.quality_gate.sab_parser import SABSpec` → 三檢查皆 False → return None → line 639 的 `if target_layer and target_layer not in allowed` 短路，cross-layer import 未被偵測。
- **Referee reason**: `sab_amender.normalize_sab_module_to_dotted` 存在但 build layer_to_modules 時沒呼叫。
- **Fix**: `mod_norm = mod.replace(".", "/")` 後再比，或兩邊都 canonicalize 成 dotted。

### [HIGH] finalize_gate 對 None score 觸發 TypeError
- **File**: `harness/harness_bridge.py:2056`
- **Function**: `HarnessBridge.finalize_gate`
- **Defect**: `score = dim_data.get("score", 0.0)` 在 `"score": null` 時回傳 None，隨後 `min(None, _spec_cap)` 炸 TypeError。
- **Failure scenario**: Gate 1 per-FR 啟用 TEST_SPEC cap 時，agent 寫 `"test_coverage": {"score": null}` → uncaught TypeError 繞過 GateBlockedError/FileNotFoundError contract。
- **Referee reason**: `dict.get(k, default)` 只在 key 不存在時套 default；framework 自己在 2244 已知 None pattern。
- **Fix**: `score = dim_data.get("score") or 0.0`；threshold 同樣 coerce。

### [HIGH] PhaseAuditor cache key 只用 candidates[0]
- **File**: `scripts/phase_auditor.py:506`
- **Function**: `PhaseAuditor._resolve`
- **Defect**: `key = candidates[0]`，candidates[1:] 被丟棄；不同 fallback list 撞同一 key 拿到 stale result。
- **Failure scenario**: Call A `_resolve(["SRS.md","01-requirements/SRS.md"])` → cache `SRS.md→01-requirements/...`；Call B `_resolve(["SRS.md","docs/SRS.md"])` 直接 hit stale，回錯的 SRS.md 路徑。
- **Referee reason**: lines 508-511 直接 trace 確認 key collision。
- **Fix**: cache key 改 `tuple(candidates)`，或以 resolved path 為 key、miss 才重算。

### [HIGH] cron_drift_monitor max() on severity strings
- **File**: `scripts/cron_drift_monitor.py:124`
- **Function**: `_run_monitor`
- **Defect**: `max(items_sev)` 做 lex 比較；CRITICAL<'H'<'L'<'M' 與語意相反。
- **Failure scenario**: `['CRITICAL','HIGH']` → `'HIGH'`；`['CRITICAL','HIGH','LOW']` → `'LOW'`，worst_severity 永遠低報。
- **Referee reason**: DriftSeverity enum 字面值（LOW/MEDIUM/HIGH/CRITICAL）無 numeric rank。
- **Fix**: map 成 rank dict (CRITICAL=4…INFO=0) 再 max；或定義 IntEnum。

### [HIGH] GateResult.open_critical 被 None 污染
- **File**: `harness/harness_bridge.py:2278`
- **Function**: `HarnessBridge.finalize_gate`
- **Defect**: `raw.get("open_critical_count", raw.get("open_critical", 0))` 在 JSON null 時回 None，line 2323 `result.open_critical == 0` 為 False，gate 永遠 blocked。
- **Failure scenario**: `{"overall_score":85.0,"open_critical_count":null}` → 滿分仍 GateBlockedError，message 只印分數不印 None 欄位。
- **Referee reason**: GateResult dataclass 型別標 int 但 runtime 無強制；無 upstream None→0 guard。
- **Fix**: `int(raw.get("open_critical_count") or raw.get("open_critical") or 0)`；high 欄位同樣處理。

### [MEDIUM] run_stryker_precheck FileNotFoundError 未捕
- **File**: `core/quality_gate/mutation_enforcer.py:524`
- **Defect**: `subprocess.run(["npx",...])` 無 try/except，僅 timeout handler；缺 npx 會炸 traceback 而非回 `(False,"...")`。
- **Fix**: `shutil.which("npx")` 預檢，或加 `except FileNotFoundError`。

### [MEDIUM] AutoFixEngine round counter 永不遞增
- **File**: `core/auto_fix/__init__.py:161`
- **Defect**: `_round_counters[round_key] = context.retry_count`（指派非累加），HR-12 永遠不觸發。
- **Fix**: engine 內 `+= 1`；統一 max_rounds 來源。

### [MEDIUM] _crg_enrich_gate_findings 直接 mutate caller's dims
- **File**: `harness/harness_bridge.py:442`
- **Defect**: 步驟 1-3 對 `_d.issues.append(...)`；override 函式卻明講「不 mutate」。
- **Fix**: 全程 `dataclasses.replace(_d, issues=_d.issues + [new])`。

### [MEDIUM] spec_logic_checker FR regex 沒 anchor + 不去 fenced code
- **File**: `scripts/spec_logic_checker.py:235`
- **Defect**: `r'\|\s*FR-(\d+)\s*\|([^\n|]+)'` 無 `^`、無 MULTILINE，code block 內 `| FR-99 | placeholder |` 會被當真實 FR；duplicate FR 後寫前。
- **Fix**: `re.MULTILINE + ^`；跳過 ``` fence；duplicate warn。

### [MEDIUM] harness_cli gitleaks 子行程無 capture、無 timeout
- **File**: `harness_cli.py:6086`
- **Defect**: `subprocess.run(["gitleaks","detect","--source","."], cwd=...)` 沒 `capture_output`/`text`/`timeout`。
- **Fix**: 加三個 kwarg，non-zero 才 log；timeout 用 `get_timeout("gitleaks")`。

### [MEDIUM] Gate4 issue_registry_path traversal
